# 🛡️ ShadowWatch

An AI-powered Cybersecurity Threat Monitoring Dashboard built using React, FastAPI, and MongoDB.

## 🚀 Features

- 🔐 JWT Authentication
- 📊 Interactive Dashboard
- ⚠️ Threat Monitoring
- 📈 Analytics & Charts
- 🔔 Notifications
- 📄 Reports Export (PDF / Excel / CSV)
- 👤 User Management
- 📝 Audit Logs

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios
- Recharts

### Backend
- FastAPI
- Python
- MongoDB
- JWT Authentication

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/karthikmukesh19-gif/ShadowWatch.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
